# Automa

Application Android de widgets personnalisables pour regrouper des informations utiles directement sur l’écran d’accueil.

## Présentation

Automa est consacré à la personnalisation de l’écran d’accueil Android au moyen de widgets et de réglages visuels.

La documentation du projet présente notamment les catégories suivantes :

- horloge numérique et analogique ;
- calendrier et date ;
- batterie ;
- catalogue de widgets et réglages d’apparence, notamment les couleurs, la transparence, l’arrondi et l’effet verre.

La disponibilité exacte d’un modèle ou d’un réglage peut dépendre de la version installée. Les notes de publication et l’application installée sont les références à consulter pour une fonctionnalité précise.

## Santé Connect et appareils connectés

Le projet a pour objectif d’explorer l’accès à des données provenant de Health Connect et d’appareils compatibles. La présence d’une intention ou d’une intégration expérimentale ne garantit pas que toutes les données soient disponibles sur chaque téléphone, montre ou écouteur.

La disponibilité dépend notamment :
- des applications qui écrivent des données dans Health Connect ;
- des autorisations accordées par l’utilisateur ;
- des données effectivement fournies par l’appareil et l’application compagnon ;
- de la prise en charge dans la version d’Automa installée.

Ressources officielles :
- [Health Connect](https://health.google/health-connect-android/)
- [Documentation Android — Health Connect](https://developer.android.com/health-and-fitness/guides/health-connect)

## Installation Android

1. Ouvre la page de la [Release Automa](https://github.com/dartist-fr/automa/releases/latest).
2. Télécharge le fichier APK présent dans la section **Assets**.
3. Ouvre le fichier sur ton téléphone Android.
4. Si Android le demande, autorise temporairement l’installation depuis cette source dans les paramètres affichés.
5. Confirme l’installation puis ouvre Automa.

Installe uniquement un APK provenant d’une Release de confiance. Android peut afficher un avertissement pour une application installée en dehors du Play Store.

## Dépannage et signalement

Si l’installation échoue :
- vérifie que le téléchargement de l’APK est complet ;
- vérifie la compatibilité avec ta version d’Android ;
- si une ancienne version est installée, une signature différente peut empêcher la mise à jour ;
- consulte les notes de la Release concernée.

Pour signaler un problème, indique la version d’Automa, le modèle du téléphone, la version Android, les étapes pour reproduire le problème et le résultat observé. N’ajoute aucune donnée personnelle ou donnée de santé dans une issue publique.
